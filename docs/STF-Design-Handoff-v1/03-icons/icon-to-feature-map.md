# STF Icon → Feature Mapping — v1.0
All names are **Lucide** icon names. One meaning per icon; never reuse an icon for two meanings in the same surface.

## Leave
Request `calendar-plus` · Approve `check` · Reject `x` · Half day `calendar-minus` · Emergency leave `triangle-alert` · Leave balance/history `calendar-search`

## Tasks
Create `plus` · Assign to person `user-plus` · Priority high `arrow-up` / medium `minus` / low `arrow-down` · Due date `calendar-clock` · Time frame `timer` · Attach proof required `paperclip` · Photo proof `camera` · File proof `file-up` · Submitted for review `send` · Completed `circle-check-big` · Overdue `clock-alert` · Reassign `repeat-2` · Recurring `refresh-cw` · Comment `message-square`

## Payroll
Payroll run `calculator` · Payslip `file-text` · Download `download` · Adjustment `sliders-horizontal` · Advance `hand-coins` · Incentive `trending-up` · Deduction `trending-down` · Approve & lock `lock` · Unlock (audited) `lock-open` · Amount `indian-rupee`

## Configuration & governance
Module toggle `toggle-right` / `toggle-left` · Feature control `sliders-horizontal` · Dependency warning `git-merge` + warning colour · Affected users `users` · Audit event `history` · Permission `key-round` · Role `shield` · Sensitive data `eye-off` · Export `share` · Policy `scroll-text` · Branch `map-pin-house`

## Feedback & system
Success `circle-check` · Warning `triangle-alert` · Error `circle-x` · Info `info` · Loading `loader-circle` (spin) · Retry `rotate-cw` · Search `search` · Filter `funnel` · Sort `arrow-up-down` · Close `x` · More `ellipsis-vertical` · Back `chevron-left` · Expand `chevron-down` · Empty state art `inbox` (in illustration frame only)

## Explicitly not used
`eye` for "view employee" (use `file-user`), `crosshair`/`radar` for location, `fingerprint`, `scan-face`, `siren`, `gavel`, `shield-alert` on employee screens.
