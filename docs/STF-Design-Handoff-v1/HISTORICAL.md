# Historical — Sudarshan Task Force (STF) design handoff

This folder is the original design handoff for the product that became **FlowHRMS by Flowacord** (rebranded 14 September 2026). It is kept unchanged as the record of the design system's origin. The STF logo, Chakra mark, navy/orange palette and Schibsted/Archivo type in these files are retired; the current brand is documented in `docs/md/BRAND-GUIDELINES.md`, and the approved Flowacord assets live outside the repository.
